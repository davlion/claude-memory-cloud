# Contributing

This is a personal project, shared as is. I'm not taking pull requests, issues or feature requests, and I don't offer support.

You're welcome to fork it and make it your own: the [MIT license](LICENSE) allows it. The [design decisions](docs/DECISIONS.md) and the [threat model](docs/THREAT-MODEL.md) explain why it's built the way it is, which helps if you change it.

To report a security problem, see [SECURITY.md](SECURITY.md).
